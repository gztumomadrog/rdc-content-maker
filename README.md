# RDC Content Maker

RDC Content Maker is a browser-based tool for preparing branded square images for social media. It supports photo templates, text layouts, image positioning, platform previews, and direct image downloads.

## Run locally

Open `index.html` in a modern browser. All image processing happens locally in the browser and no server is required.

## Publish with GitHub Pages

In the repository settings, open **Pages**, select **Deploy from a branch**, and publish the root of the `main` branch.
